# Dojo Deckbuilder v2.0 — Overhaul Plan

## North star

Dojo Deckbuilder v2.0 is a tactical martial-arts comedy game that finishes in one session, rewards mastery across repeat plays, and produces stories players want to retell. Its humor is original Paper-Fu: absurd, sincere, and mechanically meaningful.

## Non-negotiables

- Keep the H.I.Y.A.H. round, zone combat, Focus market, learned Combos, Locations, and multiple modes as the foundation.
- Do not add another general currency, universal tracking board, forced roleplay, or mode-specific base stats.
- Keep the Belt track as one clear, visible curriculum exam at a time—not a second task deck.
- Use original Paper-Fu comedy. Avoid copyrighted parody or reference-dependent jokes.

### Phase 1 — Paper-Fu identity and Belt curriculum

- [ ] Write a one-page tone bible: absurd martial-arts sincerity, story hooks, voice, and hard exclusions.
- [ ] Rename every Belt task as a visible curriculum exam and give each a brief ceremonial callout.
- [ ] Reformat Belt cards/reference so players visibly mark an exam as **PASSED** before promotion.
- [ ] Confirm that each Belt exam teaches one core skill and has one unambiguous completion condition.

### Phase 2 — Reversal interaction package

- [ ] Finalize a Paper-Fu-native reversal mechanic with exact timing, ownership, XP, Combo, and Boss rules.
- [ ] Add a compact glossary entry and combat example.
- [ ] Create a small core package of Reversal defenses, a Combo, an Item, a Location, and one Boss response.
- [ ] Playtest the package specifically for stalling, rules ambiguity, and reaction-stack feel.

### Phase 3 — Card-role rebuild

- [ ] Classify every card as Foundation, Build-around, Disruption, or Story.
- [ ] Flag duplicate conditional-damage cards for rewrite, consolidation, or expansion placement.
- [ ] Build support packages for Tempo, Reserved cards, exhausted Equipment, armor interaction, and Block/Counter payoffs.
- [ ] Add light Callout cards: read the line aloud for theater, never as a punitive roleplay requirement.

### Phase 4 — Replayability architecture

- [ ] Define themed setup modules: Character roster, Market mix, Combo mix, Location mix, and Boss package.
- [ ] Give each expansion a distinct mechanic package and comedic premise instead of a generic pile of cards.
- [ ] Add setup labels so a game announces its “episode” before the first Honor Phase.
- [ ] Establish a 60–90 minute target for the recommended format, then test first-game and veteran-game pacing separately.

### Phase 5 — Content, rules, and website

- [ ] Rewrite names, rules text, flavor, and art briefs against the Paper-Fu tone bible.
- [ ] Update rules, glossary, Quick Start, and the card library together for every mechanical change.
- [ ] Run simulation and human-table playtests for every mode before merging v2.0 into `main`.
- [ ] Release v2.0 only after the catalog, site counts, and print data agree.

## First vertical slice

The first implementation slice is deliberately small: finalize the reversal mechanic, give it a rules/glossary entry, add five to seven representative cards, and present the Belt exams as named curriculum tests. It proves the new identity without destabilizing the entire game.
